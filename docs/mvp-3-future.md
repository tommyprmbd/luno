# MVP 3 — Future Scope (not committed)

**Status:** `NOT IN SCOPE` for the current effort.

MVP 3 is a placeholder for capabilities that require a backend or multi-device
experience. **Do not begin this work** until MVP 2 is stable and the scope is
explicitly agreed.

## Potential candidates

- User accounts and authentication.
- Backend API and database.
- Cloud backup and cross-device synchronization.
- Import/export or account-level data recovery.
- Additional analytics based on synchronized history.

These are ideas, not approved requirements. Keep the app local-first until there
is a deliberate decision to change this.
